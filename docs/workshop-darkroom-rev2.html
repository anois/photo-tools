DARKROOM DISCIPLINErev.2 · 实施规格

暗房纪律 rev.2

方向 B 定稿细化：全部 5 个工具面板、交互态规格、移动端 sheet、实施计划。 整份文档就跑在最终 token 上 —— 你现在看到的就是工作台完工后的氛围。

一句话纪律：琥珀 = 人的手迹。 机器的默认态一律石墨；凡是被人碰过的东西 —— 拨过的旋钮、手写的 EXIF、正在用的工具、有改动的面板 —— 才亮起安全灯。整个抽屉只有这一个光源（危险动作的红除外）。

字体角色

  • Hanken Grotesk：标题（600）与正文（400）。工作台内废除 Fraunces 斜体 —— 意大利斜体衬线只保留给主界面的 LOOK 语境。
  • JetBrains Mono：eyebrow / 标签 / 读数 / 卡签，读数一律 tabular-nums。
  • Special Elite：全抽屉唯一的材质字体特例 —— Notation 的「手写覆盖」列。打字机字 = 人手写的东西，恰好与琥珀语义同构（见 03）。

节奏

  • 间距 4/8px 网格：行内 8 / 行间 7 / 卡内边 14 / 面板边 18 / 区块间 12。
  • 圆角一律 4px（chip 3px，dock pill 14px 沿用）；描边一律 1px hairline（--gl）。
  • 动效只允许两处：安全灯 rail 的 160ms 淡入、sheet 上滑（现有）。其余交互零动画 —— 暗房里手要稳。

六个状态，一条规则

05实施计划

两个 Phase，一次 PR 一个

Phase内容触面
P1 · 换皮 chrome 全量重做：dock / 面板头（废斜体）/ 卡片统一（删 7 套材质卡 CSS：.bg-rack 混音台、.torn-card 牛皮纸、.filmmf-card、gallery / instax / slide 卡、1.12.0 的 .ht-card 理索卡）/ 页脚 / 移动端 sheet 调色 / 读数「默认」→「—」（改 frame.defaultReadout 双语值） styles.css 为主 + i18n.js 两行 · 版本 PATCH（视觉重排 = 1.12.x）
P2 · 点灯 touched 语义落地：中央 setKnobReadout(el, valueText|null) 助手替换各 sync 点的裸 textContent 写入，顺带挂 .is-set 类（琥珀读数 + 填充轨）；dock 修改点换琥珀 app.js（~30 个旋钮的 sync/wiring 收口到一个助手）· MINOR

红线（照 CLAUDE.md 既有教训）

  • 删材质卡 CSS 块前先 grep 共享选择器 —— 1.10.7 删裁切弹窗 CSS 连带删掉 .modal-x 基础规则的事故不能重演；.caliper-row / .caliper-slider / .caliper-toggle-row 是跨面板共享件，必须先确认归属再动。
  • hover 一律走亮度不走位移（iOS :hover 黏滞坑），保留 @media (hover:hover) 门控。
  • Compose 暗房弹窗、LOOK 选择器、lookbar都不在本次范围 —— Compose 本来就是这套语言的源头，主界面另议。
  • 验收路径：dev server + 你逐面板过一遍（桌面 + 手机），smoke 与本次无关（纯 CSS 不触管线）。
待确认后开工

三个可以现在拍的细节：① 读数「默认」→「—」是否 OK（信息密度换极简）；② Notation 手写列保留 Special Elite 打字机字（全抽屉唯一材质字体特例）；③ 印记面板的红蜡从面板撤到放置台。默认我按本稿执行，有异议说哪条即可。
