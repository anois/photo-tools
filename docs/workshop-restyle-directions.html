WORKSHOP RESTYLE三个方向 · 供拍板

工作台三案

针对工作台「The Bench」的美术风格重设计。三案共用同一结构（5 工具坞 + 面板 + 页脚，控件与 id 一字不动 —— 这是一次 reskin，不动交互骨架），分歧只在一件事上：这间工作台是什么房间。 每案都以 1:1 抽屉实宽（440px）静态还原同一屏内容（◉ 仪器 · frosted-noir 卡），可直接对照。

00现状诊断 · 为什么显得「丑」

问题不在密度，在于三套语言互相打架

  • 三套色温打架。金棕 chrome（老金楼感）× 蓝灰 rack 卡面 × 正红滑块 —— 三个光源、三种材质，没有一个统一的「房间光」。
  • 每张仪器卡自成主题乐园。牛皮纸撕纸卡、奶油制版卡、皮革幻灯卡……切一次相框换半个抽屉的皮肤，而抽屉 chrome（金棕）跟哪张卡都不搭。「物质化面板」的概念是对的，剂量超了。
  • 四种字体声音挤在 60px 里。金框 mono eyebrow + 意大利斜体衬线标题 + 无衬线提示 + mono CH 编号 —— 头部三行换了四次声音。
  • 纵向节奏失衡。CH 通道行高 ~120px 的松散 vs 页脚的局促；一屏装不下「光影」区，永远要滚。
  • 「默认」读数列是噪音。右侧一列重复的「默认」占掉 44px 宽却不传递信息 —— 未触碰的旋钮不需要说话。

为什么成立

  • 亮抽屉 × 暗画布 = 天然图底分离 —— 照片永远是屏幕上最暗、最彩色的东西，工作台退成一张纸。
  • 与半调设计稿（你刚验收的那份）同语言：注册十字准星滑块、朱红读数、点网纹卡面 —— 产品的 Print 叙事从相框长进工具本身。
  • 仪器卡统一为同一种纸上「工单」：每帧只保留一个材质色签（右上角 ■ + 帧名），主题乐园问题根治。

取舍

  • 最大改动量：全部卡面重绘（但结构不动，纯 CSS）。
  • 暗环境修图时亮面板可能晃眼 —— 需要实机验证一晚上的手感。

移动端

底部 sheet 变成一张「从桌面抽出的工单」，顶边一条藏青裁切线 + 朱红页码；工具坞转为 sheet 顶部纸签横排。

为什么成立

  • 成本最低、风险最低：所有问题都是「减法」可解 —— 去金棕、统一滑块、收编卡面。
  • 与 Compose 暗房形成一套世界观：Compose 是取景的暗房，工作台是修整的暗房，同一盏安全灯。
  • 「已调整」语义交给琥珀：触碰过的滑块出现琥珀填充轨 + 琥珀读数，未触碰的只有一个「—」—— 一眼看清这张照片改过什么（比一列「默认」信息量高一个量级）。

取舍

  • 放弃「物质化仪器卡」的戏剧性 —— 帧的个性降为一条 2px 色条 + 卡签文案。你当初喜欢那套材质卡的话，这案会觉得素。
  • 近单色系，气质靠克制撑，细节（4/8px 网格、tabular 数字）必须做满否则显得没做。

移动端

bottom sheet 原结构不动，只换皮；安全灯 glow rail 转到 sheet 顶部把手上（当前工具的琥珀亮线）。

为什么成立

  • 行高恒定 + 全表格化 → 密度翻倍，仪器 + 光影一屏放完，滚动基本消失。
  • 「AUTO / 数值」的相机语义天然解决「默认」读数噪音 —— 相机用户看一眼就懂。
  • 黄色选中条自带键盘导航叙事，桌面端 J/K 上下行、◂▸ 调值的操作模型顺手就来（后续可加）。

取舍

  • 最激进：滑杆改步进器是交互面的改动，超出 reskin 边界（可以保留拖拽轨 + 值步进双通道折中）。
  • 气质冷硬，与主 app 的 Fraunces 人文调有断裂感 —— 工作台会像「另一台设备」。这既是风险也是魅力。
  • 纯黑 + 黄是相机的语言，但也是行车记录仪的语言，执行差一点就廉价。

移动端

页签横条天然适配 bottom sheet 顶部；恒定行高对拇指滚动最友好；步进器触控目标偏小，需要 44px 化处理。

推荐

首推 B（暗房纪律）：它直接治的就是你说的「丑」—— 丑来自打架，不来自暗色本身。一盏琥珀灯 + 石墨三阶 + 触碰态语义，改动是纯减法，一次 PR 能落地，且与 Compose 组成完整世界观。

如果想赌一次气质跃迁，选 A：它跟你刚拍板的半调 / Print 方向天然同频，会让整个产品从「暗色工具站」变成「纸上印厂」，但值得先做一晚上的实机亮度手感测试。C 建议只吸收它的两个器官 —— 「AUTO/数值」读数语义 + 恒定行高的密度纪律 —— 移植进 A 或 B。
